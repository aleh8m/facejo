# Facejo

موقع Facejo العربي لتصميم وتطوير المواقع والبرامج، مع العروض والتصاميم التوضيحية وفاحص النطاقات والتواصل عبر واتساب.

## التشغيل محلياً

يتطلب Node.js 22 أو أحدث، دون حزم إضافية:

```sh
npm run build
npm run dev
```

افتح http://127.0.0.1:4174 .

## النشر على GitHub Pages

1. فعّل **Settings → Pages → Source → GitHub Actions**.
2. كل تحديث لفرع `main` يشغّل `.github/workflows/pages.yml`، يفحص المصدر، ويبني الموقع وينشره.
3. يمكن إعادة التشغيل يدوياً من Actions → Publish Facejo website.

يُضبط عنوان الموقع ومسار المستودع تلقائياً من GitHub Pages، وتُفحص الروابط والشعار والخريطة قبل النشر. لا توجد مفاتيح أو كلمات سر في المصدر.

## التعديل

- `build.mjs`: محتوى الصفحات والقوائم والأسعار والشعار.
- `src/style.css`: التصميم المتجاوب والحركات.
- `src/app.js`: القائمة والفلاتر ونموذج الطلب وفاحص النطاقات.
- `src/assets/`: صور الشعار PNG.
- `dist/`: المخرجات المنشورة، يتم توليدها أثناء النشر ولا تُرفع إلى Git.

السعر المعلن: 50 دينار للسنة الأولى لصفحة عربية واحدة مع الاستضافة ونطاق فرعي وHTTPS وجولة تعديلات. النطاق الخاص خارج الباقة. رقم واتساب: +962791698516.

فحص RDAP يميز التسجيل الموجود من عدم وجود سجل؛ لا يضمن قابلية الحجز أو السعر. نطاقات .jo عبر dns.jo. نموذج التواصل يجهز رسالة يراجعها الزائر قبل فتح واتساب ولا يخزنها على خادم.

الموقع لا يحتاج خادم تطبيقات أو قاعدة بيانات. التصاميم المعروضة توضيحية وليست أعمال عملاء. حقوق العلامة والتصميم محفوظة لصاحب Facejo؛ لم تُضف رخصة تمنح إعادة استخدام عامة.
