# FaceJo | فيس جو لتصميم المواقع وتطوير البرمجيات

الموقع الرسمي لمشروع **FaceJo** لتصميم وتطوير المواقع الإلكترونية، البرمجيات والأنظمة المخصصة، وتطبيقات الهواتف والمتاجر الإلكترونية.

## ملفات المشروع الأساسية
- `index.html`: النسخة الكاملة المستقلة للموقع في الجذر الرئيسي (تعمل مباشرة على GitHub Pages).
- `build.mjs`: سكربت توليد صفحات الموقع المتعددة داخل مجلد `dist/`.
- `verify-build.mjs`: سكربت التحقق من سلامة الصفحات والروابط بعد البناء.
- `src/style.css`: ملف التنسيقات بالهوية الفاتحة الجديدة (`#FFFFFF`, `#0078AD`, `#67C3EF`, `#E49B2B`).
- `src/app.js`: الكود التفاعلي للترويسة المتحركة وأداة فحص النطاقات ونماذج واتساب.
- `src/assets/facejo-promo-card.jpg`: صورة الكرت الدعائي الرسمي للمشروع.
- `.github/workflows/pages.yml`: إعداد النشر التلقائي على GitHub Pages.

## نشر التحديث
فك ضغط الحزمة ثم ارفع الملفات والمجلدات مباشرة إلى جذر مستودع aleh8m/facejo عبر Add file → Upload files. لا ترفع ملف ZIP نفسه ولا مجلدًا أبًا يحتوي المشروع. اترك إعداد Pages على GitHub Actions. سيتم النشر تلقائيًا بعد Commit changes.

تم ضبط البناء لنشر الصفحة الرئيسية الكاملة من index.html، وإصلاح مسارات GitHub Pages والتحقق من الصفحات والأصول المحلية.
